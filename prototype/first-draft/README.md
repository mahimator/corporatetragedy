# Corporate Tragedy Browser · UI Draft 01

This is a standalone, single-file clickable design prototype for the first browser UI.

## Run it

Open `index.html` directly in any modern browser.

## Included in this draft

- Dark IDE-inspired browser chrome
- Single-tab visual
- Address bar with URL navigation and search fallback
- Back, forward, reload controls
- Home view and shortcut tiles for WhatsApp, YouTube, Instagram and YouTube Music
- Side rail, status strip and bookmark toggle

## Important limitation

This draft's browsing area is an iframe. Some sites intentionally block iframe embedding, and it is not a full browser engine. The native browser build will replace this area with CEF, which provides real Chromium navigation, browser processes, cookies, storage and web compatibility.

This draft is for evaluating the layout and interactions, not claiming the Chromium implementation is already built.
